# Frontend Bundle Size V1：Next.js 与 TanStack 对比

> 本文保留迁移期间已经记录的 Next.js 与 TanStack 产物对比。当前三个应用的最新
> production snapshot 见 [`v2.md`](./v2.md)。

## 结论

- Landing 有完整的 Next.js 首页与 TanStack 首页对照记录；TanStack 改版后的首页
  `JS + CSS gzip` 从 `618,241 B` 降到 `390,388 B`，减少 `36.9%`。
- Community 的旧 Next.js 应用名为 Main。已有记录显示，TanStack Community 的
  client route assets gzip 总和比 Main 减少 `18.8%`；当前 snapshot 相对该基线减少
  `19.1%`。两者的 route 集合和构建器不同，只能作为方向性比较。
- Dash 的旧 Next.js 应用名为 Dashboard。当前历史记录没有保留可复核的 Dashboard
  bundle 数字，因此不补填估算值；Dash 当前值记录在 [`v2.md`](./v2.md)。

## Landing：首页实际引用资源

该表只统计首页 HTML 明确引用的 JS 与 CSS，不包含未被首页引用的 wallpaper、图标和
其他静态部署资产；不把 HTML 计入 client bundle。

| 阶段                   | 应用 / 框架              |  JS 文件数 |        JS + CSS gzip | 相对 Next.js 减少 | 记录日期   |
| ---------------------- | ------------------------ | ---------: | -------------------: | ----------------: | ---------- |
| Next.js 线上版本       | Landing / Next.js        | 15 + 1 CSS | 618,241 B / 618.2 KB |                 — | 2026-08-26 |
| TanStack rewrite       | Landing / TanStack Start | 13 + 1 CSS | 497,167 B / 497.2 KB |             19.6% | 2026-08-26 |
| TanStack rewrite V2 后 | Landing / TanStack Start |  5 + 1 CSS | 390,388 B / 390.4 KB |             36.9% | 2026-08-26 |

对应的 Landing V2 记录还测得：TanStack 首页 HTML + JS + CSS 为 `460,313 B gzip`，
Next.js 线上响应为 `627,603 B gzip`。这不是同一种 HTML 输出：TanStack 返回完整
prerender 页面，而旧 Next.js 响应包含 CSR bailout，因此不能把它解读成单纯的框架
开销对比。

## Community：Main 与 Community

这里沿用历史 baseline 的口径：统计 client chunk 目录中所有文件的 raw 总和，以及
每个文件独立 gzip 后的大小总和。revision worker 单独统计，不混入 client route assets。

| 阶段          | 应用 / 框架                | 文件数 |         raw | per-file gzip sum | 相对 Main / Next.js 减少 |
| ------------- | -------------------------- | -----: | ----------: | ----------------: | -----------------------: |
| 历史记录      | Main / Next.js             |     72 | 4,221,118 B |       1,193,838 B |                        — |
| 历史 baseline | Community / TanStack Start |    149 | 3,412,452 B |         969,939 B |                    18.8% |
| 当前 snapshot | Community / TanStack Start |    100 | 3,461,695 B |         966,381 B |                    19.1% |

旧 Main 与 Community 的构建器、route 集合不同，不能将两列数字当作严格的 Next.js
与 TanStack runtime benchmark。历史 Community baseline 还记录了 revision worker
`266,025 B raw / 68,759 B gzip`；当前值见 [`v2.md`](./v2.md)。

百分比按 `(Next.js 基线 - TanStack 数值) / Next.js 基线` 计算，使用表中相同的 gzip
口径；不是把 HTML、revision worker 或浏览器实际 waterfall 混入计算。

## Dash：历史记录缺口

旧 Dashboard 的可复核 bundle 表没有随迁移记录保留下来。V1 不用当前 Dash 数字倒推
Next.js 数字，也不把不同构建阶段的日志输出拼成一份伪对比；当前 Dash 的完整 client
assets 统计以 V2 为准。

## 口径说明

- `raw` 是构建文件的字节数。
- `gzip` 是每个文件分别压缩后求和，不是把所有文件拼接后再压缩，也不是浏览器
  waterfall 的实际传输量。
- Landing 的表是首页引用资源口径；Community 的表是整个 client route assets 目录
  口径，两者不能直接横向比较。
- 线上 CDN 压缩、缓存、HTTP/2/3 请求调度和 route preload 都可能使实际传输量不同。
