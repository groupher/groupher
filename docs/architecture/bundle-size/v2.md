## 测量方法

每次更新 bundle 时执行对应的 production build：

```bash
pnpm run build:prod:landing
pnpm run build:prod:community
pnpm run build:prod:dash
```

然后统计 `frontend/<app>/dist/client/assets` 下的文件，分别计算 raw、逐文件 gzip 和
逐文件 Brotli 的字节数总和。Community 与 Dash 的
`dist/client/worker-revision-diff.js` 单独记录。该方法适合稳定比较构建产物，不等同于
线上 CDN response size、浏览器缓存后的请求量或浏览器实际完成的首屏 waterfall。
页面首屏数据则来自 production Worker 返回的 SSR HTML，只统计 HTML 中实际引用的 JS/CSS
文件，并将 HTML 自身单独列出。
