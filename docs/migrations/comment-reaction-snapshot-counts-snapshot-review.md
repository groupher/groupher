## 4. 验证状态与剩余差异

- 本轮可执行验证只涉及文档、manifest、正文 SHA、映射及既有测试路径；不执行冻结 `.txt`、业务测试、编译、维护任务、迁移或 DB 读写。
- 原 baseline 是哈希基线，原正文不可恢复的限制保留；已移除的正文副本无法再用于未来工作区逐行 diff，不追溯伪造原版本。
- 共享评论 B0 总体验收仍未通过。剩余事项分为 F01–F10 的计划/联合验收差异，以及 [捕获后工作区差异](comment-reaction-snapshot-counts-remaining-differences.md)，不能用同一个“drift 待复核”笼统替代。
- 原六文件 review 为历史证据；本报告的“已复核”仅针对 `20261105T074802Z` 的 49 个输入。捕获后源码即使继续变化，也不修改这里的 SHA/正文或改写成实时工作区结论。
